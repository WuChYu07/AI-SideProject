🧵 Why use a thread in the voice_assistant?
🎵 While the music is playing, the assistant still needs to listen for user commands in the background.
By using a separate thread, the system can multitask — continuing speech detection without interruption.
This ensures a smoother and more responsive user experience 🚀🎧
